# Upload instructions (private-first)

1. Sign in to the GitHub account intended to hold the research repository.
2. Visit https://github.com/new and create a NEW PRIVATE repository named `uzbekistan-openbudget-cohort-audit` (or another distinct name). Do not initialize with an unrelated project.
3. Upload the contents of this directory (not a top-level extra folder) via `Add file` → `Upload files` OR send the empty repository URL in ChatGPT so the connected GitHub integration can write the text/CSV files.
4. Verify `README.md`, both CSV tables and `scripts/validate_summaries.py` are visible in the private repository.
5. Do NOT upload the 33-sheet provenance workbook or the journal ZIP. Do not change visibility until permission, author approval and anonymous-review considerations are resolved.
6. GitHub commits are not permanent research-data DOIs. For DOI use a repository such as Zenodo after final checks.

Use the private-repo URL in the manuscript only when actual reviewer access is arranged, and use appropriately anonymous-access methods for double-anonymous review.
