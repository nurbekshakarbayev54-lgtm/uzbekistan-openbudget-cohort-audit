# Publication checklist and redistribution limits

**Do not change the visibility to public until all checks pass.**

- [ ] Both named article authors approve depositing these derived tables and code under the chosen GitHub owner.
- [ ] The repository's GitHub owner / commit history will not defeat a required anonymous-review process.
- [ ] Check official source content licensing/database rights and permitted reuse; do not assign a license to third-party records without permission.
- [ ] Select and document a clear appropriate license **only for original code/derived compilation where the authors have authority**. This draft contains no license declaration.
- [ ] Verify the provenance of each extracted project and, if claiming a complete replica, add source acquisition scripts, dated raw record hashes, project-level ID correspondence and exclusions log.
- [ ] Reconcile or explicitly preserve the published-versus-snapshot count differences.
- [ ] Confirm authors' declarations, funding statements and version approved for submission.
- [ ] If a DOI is needed, archive a reviewed release in a preservation repository such as Zenodo and cite the **actual minted DOI**; a GitHub URL alone is not a DOI.
- [ ] Update the manuscript's data availability statement **only after** a real, accessible and permitted repository deposit is established.

This package contains no private author-approval forms, personal contact details, complete third-party records or unverified raw workbook. The two CSVs are *derived summary statistics*, not complete raw data for independent reconstruction.
